One line of earned pride — a night guard who taught himself to read by the gate lamp finishes his first book at 4 a.m. A single line (160 characters) written to `output/entry.txt` by a deterministic Python program, for make.fun's "One Line of Earned Pride" bounty.

> The night guard who taught himself to read by the gate lamp finished the last page of his first book at 4 a.m. and closed it gently, like it might wake someone.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Standard library only; the same input always produces the same output bytes.
